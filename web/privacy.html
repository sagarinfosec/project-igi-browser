SITE INFORMATION

Privacy & data use

A plain-language summary of what this browser-based project needs to operate.

Game files and local storage

The original game files are not bundled with this website. If you select a game folder, the browser stores a working copy in origin-specific private browser storage (OPFS) so the game can run locally. The folder is not intentionally uploaded to this website's server by the game importer.

Preferences

Control bindings, touch layout and other player preferences may be saved in browser storage on your device. Clearing site data or using a different browser profile may reset these preferences.

Diagnostics and network features

Browser and game functionality may make network requests for the site itself and optional multiplayer infrastructure. If crash reporting is enabled in a deployment, diagnostic details may be sent to its configured endpoint. The exact data collected depends on the deployed build and hosting configuration.

Third-party services

This version of the website is designed without advertising panels or affiliate shopping placements. External links, if added by a deployment or the user, are governed by their own providers' privacy practices.

Children and personal information

Do not submit sensitive personal information through issue reports or support channels. This site does not require an account to use the browser launcher.

Policy scope

This page is a project-level summary, not legal advice. Operators who add analytics, accounts, monetization or other third-party services should update this policy to describe those services accurately before launch.
