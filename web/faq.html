TROUBLESHOOTING

Frequently asked questions

Common setup and browser issues, with practical checks to try before restarting.

Setup & game files

Does the website include the original game?

No. You must provide a compatible copy you own. When asked, select the folder containing igi.exe, MISSIONS and COMMON. The browser imports it into local private storage.

Do I need to import the folder every time?

Normally, the browser keeps the imported files in its origin-specific private storage, so later launches can reuse them. Clearing site data, changing the domain or using a private browsing session may remove that stored copy.

Browser compatibility

The launcher says cross-origin isolation is missing. What should I do?

Use a deployment that sends the required COOP/COEP headers, open the site directly rather than inside an embedded frame, and use a current supported browser. Hosting configuration can prevent the game from starting even when the page itself opens.

I see a black screen or a WebGPU error.

Update your browser, enable hardware acceleration, update graphics drivers and close/reopen the tab. Some remote desktops, virtual machines, older browsers and unsupported GPUs cannot provide a usable WebGPU adapter.

Why is the first launch slow?

The first setup imports the game files and prepares browser storage. Mission loading can also take time. Keep the tab open and wait for the launcher status; do not repeatedly refresh during import.

The browser reloads during gameplay.

This can happen if the device runs out of memory. Close other tabs/apps, avoid running multiple game instances, and try a desktop browser or a device with more available memory.

My mouse stopped turning the view.

Click inside the game to recapture the pointer. If needed, press Esc to release it and then click the game again.

Does mobile gyro work on every phone?

No. Motion permissions and sensor APIs vary by device and browser. If gyro aiming is unavailable, turn it off and use touch swipes to aim.

Still stuck?

Note your device, browser version and the exact status/error text. See the controls guide before trying again.
