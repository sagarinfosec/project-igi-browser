About Project I.G.I.

A browser-based way to experience a tactical-action classic on compatible modern devices.

What is this site?

This website provides a browser interface for an independent technical port of Project I.G.I. The port translates the game's machine code into browser-compatible code and recreates the Windows APIs needed by the original game.

What can I do here?

  • Launch the browser player on a supported device.
  • Use keyboard and mouse or configure the touch controls on a phone or tablet.
  • Adjust bindings, sensitivity, scope options and touch layout where supported.
  • Read setup and troubleshooting guides before starting.

Bring your own copy

The original game files are not included with this website. When prompted, choose a compatible copy that you own. The browser stores the imported files in its local private storage for use on this device; the website does not upload the game folder to its own server.

Compatibility note: the player relies on WebGPU, cross-origin isolation and browser storage APIs. A page loading successfully does not guarantee that every device has a usable graphics adapter.

Ownership and affiliation

Project I.G.I. and its related names, characters and assets belong to their respective rights holders. This is an independent fan project and is not affiliated with or endorsed by the original publisher. This website does not distribute the original game.
